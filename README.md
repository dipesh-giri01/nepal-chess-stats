# nepal-chess-stats

Static dashboards on Nepali chess, served with GitHub Pages.

- `olympiad/`: Nepal at the Chess Olympiad, 2004 onward
- `youth/`: FIDE-rated youth players, U7 to U20 (rebuild data with `python3 youth/build_data.py <fide-export.json>`)
- `tournaments/`: FIDE rated tournaments held in Nepal (rebuild data with `python3 tournaments/build_data.py`)
- `dataset/nep_rated_tournaments.json`: all NEP FIDE rated tournaments from 2003 (450 events; copy from Chess Nepal Research)
- `assets/style.css`: shared styles
